# Algorithm Lab

A systematic study and experimental benchmarking of fundamental algorithms and data structures.

## Research Question

How do theoretical algorithmic complexities translate into actual performance under different input conditions?

## Objectives

- Implement fundamental algorithms from scratch.
- Verify correctness using automated tests.
- Analyse time and space complexity.
- Benchmark algorithms on different input sizes and distributions.
- Compare theoretical predictions with experimental results.
- Document findings in a research-oriented format.

## Algorithms

### Sorting
- Bubble Sort
- Insertion Sort
- Selection Sort
- Merge Sort
- Quick Sort

### Searching
- Linear Search
- Binary Search

### Data Structures
- Stack
- Queue
- Linked List
- Binary Search Tree

## Methodology

Each algorithm will be evaluated through:

1. Implementation
2. Correctness testing
3. Complexity analysis
4. Performance benchmarking
5. Experimental interpretation
